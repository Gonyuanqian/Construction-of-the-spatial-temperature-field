## 知识状态与发布

`source_checked` 仅表示本轮完成来源/定位与摘要核对，不表示农业专家已批准。`reviewer` 如实记录 Codex 初核，不冒用人类专家身份。`draft` 单元不能由当前入库脚本发布。正文为短篇中文转述，保留出处；没有把付费论文全文复制进项目。

下一阶段逐条核对：原文是否支持中文转述、否定与适用条件、勘误/撤稿状态、授权范围和项目相关性。通过后形成新的发布版本，不直接改旧版本；将审批人、日期、资料摘要与有效条件登记完整后，才改为 `published` 并建立向量索引。

具体作物温度数字需追加作物/品种、生育期、温度对象、昼夜、暴露时长和试验/规程条件，进行独立数字核对及领域审核。首批资料故意不提供可执行温度处方，也没有把论文模拟误差当成本系统误差。

## 预备检索验收问题

1. 空气测点能否代表叶片温度？应命中 `FAO217-temperature-target`。
2. 自然通风为什么与风况和温差有关？应命中 `FAO217-natural-ventilation`。
3. 高湿环境可以只按气温决定喷雾吗？应命中 `FAO217-evaporative-cooling`。
4. 育苗萌发期只测空气是否足够？应命中 `FAO217-germination-medium`，还应确认阶段。
5. 虚拟传感器和实测有什么区别？应命中 `GUZMAN2019-virtual-sensing`。
6. 文献证明任何棚只需一个传感器了吗？应命中 `GUZMAN2019-transfer-limit` 并否定这种泛化。
7. 棚里有通风，温度就一定均匀吗？应命中 `OGUNDELE2026-heterogeneity`，不编造本棚温差。
8. 这些资料足够给出人参棚的准确适温阈值吗？应指出缺少人参及阶段特定资料，不提供数字。

这些是人工设计的预备问题，不是已取得的检索准确率；首批规模不能代替正式农业评测集。

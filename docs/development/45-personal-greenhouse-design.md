# 个人温室设计与布局（2026-11-16）

用户工作台新增 `/greenhouse-design`。普通用户和管理员均只能访问自己的个人方案；管理员的棚体档案库继续维护发布配置，不与个人设计实例混用。后端业务由 Spring Boot 实现，布局生成不调用 Python 模型、天气 API 或 AgriSeek。

## 页面与数据

保持已确认的三列布局：左列四组参数，中列三维棚体及二维种植灌溉图，右列 AI 检验占位及方案信息。小屏重排以保持可操作。离页缓存个人草稿，退出账号清空上下文；持久保存需要点击保存草稿。

1. 位置与朝向：复用吉林省地点选择窗口，保存行政区、GCJ-02 经纬度、手填海拔、前端开口真北方位角。后端开口方位由前端加 180°计算。海拔允许未知，不从地图或天气推测。
2. 温室结构：小拱棚、连栋温室，长宽、拱高、覆盖材料。连栋另设跨度、栋数和檐高，总宽由服务端计算为跨度乘栋数，三维总高为檐高加起拱高度。预览采用简化拱形骨架。
3. 作物与种植：人参品种自由填写，栽培带宽、株距、中心行距、前后通道、带间通道、侧边预留。API 长度统一为 m，株行距输入以 cm 显示并转换。
4. 设备：滴灌、喷灌可分别开启；滴灌沿种植行布管，滴头间距独立保存；喷头间距、安装高度、标称覆盖半径、自动/手动位置均保存。手动选中喷头后可编辑坐标或在二维图点击新位置。

默认数值是可编辑的排布示例，不是品种或栽培参数推荐。品种、经纬度和海拔不以示例地点冒充真实输入。

## 几何排布

生产计算在 `DesignLayout`：有效种植长度 = 棚长 − 前通道 − 后通道；种植带按带宽、带间通道和侧边预留计算数量，并在棚宽方向居中。各带的行按中心行距居中布置；株距独立决定每行株数。前后通道内不自动放置植物或喷头。自动喷头按目标间距上限均布于可种植区域；手动越界位置保留在草稿中，同时显示布局提示并阻止应用到监测。

服务端返回种植带矩形、种植行、株数、喷头坐标与标称覆盖半径的配置，两个画布使用同一结果。植株多时前端抽样绘制，实际数量仍来自后端。覆盖圆仅为标称几何示意，没有计算水压、喷头型号、风、遮挡或水力均匀性。布局资源设有数量上限，避免超密配置耗尽资源。

确定性的尺寸/越界提示属于输入与布局校验，不作为 AI 检验结果。右侧 `AI 检验 · AgriSeek` 已在 2026-11-17 接入保存版本检验、结果与建议分区和历史记录；只有用户主动点击才提交模型任务，见 [AI 检验交接](46-greenhouse-ai-inspection.md)。

## 接口与权限

统一前缀 `/api/user/greenhouse-designs`，使用现有 Bearer 登录和账号上下文；不接收客户端 owner_id。跨账号访问返回 404，管理员也不会自动读取其他人的个人方案。

| 方法与路径 | 内容 |
| --- | --- |
| GET / | 本账号方案列表，limit 1–100、offset 非负 |
| POST / | 保存新方案，返回 id、revision、spec 及时间 |
| GET /{id} | 读取本人方案 |
| PUT /{id} | `{revision, spec}`，冲突返回 409，不覆盖新版本 |
| POST /preview | 输入完整 spec，生成几何布局，不持久化 |
| POST /{id}/activate | `{revision}`，冻结此版本为本账号监测配置 |
| GET /active | `{selection: null或版本快照}` |

草稿允许几何冲突以便继续修改；非法类型、非有限数、超出数值边界和过量资源请求返回 422。使用现有地区字典校验代码并由服务端补全地区名称。

Flyway V9 新建 `greenhouse_design` 和 `greenhouse_design_selection`。前者保存完整 JSON、拥有者与递增修订号；后者保存本账号已应用的不可变方案快照。修改草稿不自动改变已应用快照。应用操作按账号串行化并核对方案修订号。没有删除或覆盖既有模型、用户和气象记录。

## 用于监测的实际范围

“保存并用于监测”先保存方案，再请求后端冻结指定版本。只允许当前原型支持的小拱棚尺寸及有效地点；连栋和超出现有原型范围的设计可保存和展示，不能套用现有小拱棚模型构场。

跳转 `/live?applyDesign=<id>&designRevision=<n>` 后，监测页从服务端读取该账号的应用快照，并核对编号及修订号；客户端 URL 不能直接注入尺寸或替换方案。读取成功后应用地点和尺寸，进入现有气象查询与构场流程。未改变训练模型或天气缓存规则。

当前构场模型只使用尺寸映射和外部气象，不处理海拔、棚体朝向、覆盖材料、品种或设备动作的真实热影响，也没有验证跨尺寸精度。方案编辑支持这些字段不表示模型已经学习它们。AI 检验独立读取指定版本快照、核验依据并保存分析结果，不改变构场模型的能力范围。

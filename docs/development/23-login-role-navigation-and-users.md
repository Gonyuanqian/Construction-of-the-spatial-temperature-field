管理员和普通用户登录后都进入 `/live`，系统根地址与未知地址同样回到该用户视图。用户导航为“实时监测、实时回放、AgriSeek”。管理员右上角显示“开发者后台”，进入 `/data` 后提供数据、训练、模型库、构场、用户管理和棚体档案导航；后台不再放回放与助手入口，右上角提供“返回用户视图”。普通用户不显示后台入口，后台路由继续按管理员角色限制。双方均可从右上角账号菜单修改密码或退出。

用户视图不随管理员在后台导入训练数据而重置，往返后台保留工作台实例与结果。

原管理员文件回放后端仍为 `/api/replay/**`，不向普通用户开放。用户页面 `/replay` 是气象输入与个人结果界面，调用 `/api/user/**`，不使用管理员文件回放。`/live` 恢复原 `LiveView` 大屏，调用气象驱动的 `/api/live/**`，不探测 `/api/models` 或 `/api/dataset`。其原播放控件暂未适配新气象驱动方式，开始/下一帧会返回后端说明；后端不会恢复 24 路实测输入。详见 [本次导航与数据边界](26-user-workspace-navigation.md)。

## 登录和数据隔离

- `api/session.ts` 只在 `sessionStorage` 保存令牌及到期时刻；不保存密码或角色。新开页面/刷新后，经 `/api/auth/me` 验证身份再开放业务页。没有全局 fetch 猴子补丁，也没有开发模式免登录开关。
- `api/client.ts` 为 JSON、上传、PATCH/PUT/DELETE 和助手 SSE 统一附加 Bearer 头。不会把令牌放到 URL 或外部地址。401 清除当前会话并返回登录页，403 显示权限错误，不把正常登录错误误作会话过期。
- 登录失效、退出或切换账号时销毁 `AuthenticatedShell`，清除训练工作区、KeepAlive 画布和数据集缓存。旧请求的响应头或 JSON 内容即使晚到，也不能进入新账号工作区。
- 网络暂时断开时保留已有令牌，登录页提供会话重试；不会把连接故障显示成“还没导入数据”。用户提交气象失败时保留输入，便于修正或重试。
- 路由守卫校验角色；登录完成统一进入用户视图，包括旧登录链接携带后台回跳地址的情况。已登录管理员仍可访问明确的后台地址。后端的权限和资源授权仍是最终边界。
- 修改账号资料或重置密码会撤销目标账号的全部会话；修改自己的账号或密码后立即回到登录页。最后管理员保护由后端事务保证，前端显示其返回原因。

`sessionStorage` 的选择让同一标签页刷新保持登录，关闭标签页后不保留长期登录。后续如接入外部身份系统，可替换会话实现，但不能通过存储中的角色决定授权。

## 管理员操作顺序

1. 首次正式启动，在 Java 启动环境配置初始管理员用户名、强密码，再由 V5 迁移创建账号业务表；已有账号不会被覆盖。具体变量见后端文档。
2. 管理员登录，在右上角点击“开发者后台”，再进入“用户管理”创建普通用户账号。
3. 服务器上准备可信 G/F 气象模型包并登记、发布。当前页面可以绑定已发布模型，不承担第一阶段 G 的训练或本地 pickle 上传。
4. 在“棚体档案管理”创建市级默认或区县专用档案，填写尺寸、绑定已发布模型；同一地区只启用一份。
5. 普通用户登录后在“实时回放”选择气象所在地并提交气象，再返回“实时监测”查看原三维大屏。无地区覆盖、尺寸不兼容、无可用模型均有提示。个人历史按账号和气象地区隔离。

两输入模型只要求背景温度和光照，三输入模型另要求背景湿度。时间以浏览器本机时区填写并转为带时区的 ISO 时间传后端。页面不换算光照单位，也不重算温度；光照口径须与训练数据一致。

## 风格与代码入口

沿用现有设计令牌：管理页为浅色背景、白色卡片、青绿交互；监测页继续使用原深蓝、青色轮廓与亮蓝按钮。登录页使用同一字体、卡片和颜色令牌，棚体线稿为装饰图，不是测量数据。

| 文件 | 职责 |
| --- | --- |
| `App.vue` | 公开页面/登录工作区边界、会话变化后的销毁与跳转 |
| `components/AuthenticatedShell.vue` | 原应用外壳、角色导航、管理员训练工作区提供者 |
| `composables/useAuth.ts`、`api/session.ts` | 登录、恢复、退出、到期与可观察身份状态 |
| `router/index.ts`、`router/access.ts` | 路由角色元数据、守卫和安全回跳 |
| `views/UsersView.vue` | 账号资料与密码重置 |
| `views/GreenhousesView.vue` | 地区、尺寸、气象模型配置和匹配状态 |
| `views/LiveView.vue`、`views/UserLiveView.vue` | 原三维监测大屏、气象输入与历史结果页；当前路由不使用 `LiveRoute` 分流 |
| `api/accounts.ts`、`api/weather.ts` | 新业务类型与接口 |
| `design/forms.css` | 新管理页共用的表单、表格和分页样式 |

三维显示保留 `measured=false`；仅使用 `virtual_source` 决定虚拟源平面附近的显示透明度，不改变温度值或实测分类。

# 实时监测：外部气象概览

更新：2026-11-06。

## 页面内容与来源

`/live` 三维画布上方的蓝色概览条改为四项横排：外部温度、外部湿度、光照强度、地区。地区只显示省和市。底部环境参数中的棚内均温保留。

概览读取当前断面响应的 `live.weather` 和 `live.location`，只有响应的 `live.session_id`、`frame.n` 与当前状态一致时才展示，避免将新观测的气象值与旧场混用。

Java `WeatherLiveService.view` 为状态及网格视图附加已保存观测：

```json
{
  "weather": {"bg_temp": 22.5, "bg_rh": 61.5, "bg_light": 800.0},
  "location": {"province_name": "吉林省", "city_name": "白山市"}
}
```

`weather` 直接来自 `weather_frame` 保存的外部输入，不重新计算。`location` 保留原有完整地区对象，组件只使用省市名称，不改写历史记录。

## 缺失值和单位

- 没有当前结果、响应不匹配或数值无效时显示“暂无”；有效的 0 正常显示。
- `two` 输入方案未提交湿度时显示“未提供”。第二阶段所用的估计湿度仍可存在于计算视图中，但不能充当用户接入的外部湿度。
- 温度为 °C，相对湿度为 %。光照沿用源数据单位；当前协议没有单位转换，不能直接标成 lux 或 W/m²。
- 本次没有接入自动天气采集服务，展示的是用户已提交并保存的气象条件。

## 垂直温度分布概览（2026-11-23）

底栏“温度分布概览”改为高度—均温曲线：横轴为距地高度（m），纵轴为该高度有效网格的平均温度（°C）。后端以 `height_profile: [{z, mean}]` 返回统计，前端直接绘图，悬停展示高度与均温。

高度统计共用 `tfield.field.profile.height_temperature_profile`，汇总当前返回网格在同一高度的 x/y 有效格点；包含上部已有的模型预测值，仅排除拱外 null 和非有限值，不按 stripes 过滤高度曲线。先合并有效格点再取平均；无有效值的高度返回 null，曲线不跨空值连线。原型及旧气象保存结果均在读取视图时生成统计，无需改写历史文件或重新训练。旧回放 volume 接口也提供同一字段。全场均温、三维可查询掩膜与原模型保持原口径。

当前原型沿棚长均匀展开，因此沿棚长均温曲线无法反映截面分层；新曲线用于观察竖向温差，仍属于当前模型网格的统计。全场均温、三维构场及温差 G → F 逻辑保持原有口径。

按用户要求，温度纵轴反向显示（`inverse=true`）：上冷下暖，−5.8℃ 位于 −6.2℃ 下方，轴名标明“向下升温”。面积图填充到数值上界（`areaStyle.origin='end'`），也就是画面下边界；正温、负温及跨零数据均保持向下填充。原始温度读数不变，填充面积不作为热量或空间体积指标。

温度纵轴按实际高度均温范围选择 1/2/2.5/5 系列的刻度间隔并留少量边距，显示上下界；不再向整摄氏度取整。恒温和跨零读数也保留非零轴跨度。纵轴读数从上到下递增，坐标范围仅控制图表显示。

桌面端（至少 1200px）环境监测预警和温度概览底栏最小高度为 260px，图表随卡片伸展；中间内容和右栏使用同一网格行及纵向滚动范围，AI 农事建议固定在右栏末端，两列底边对齐。窄屏沿用分行布局。

实时页“三维信息查询”取消画布选点的“来源”行，构场前占位保持一致；两处回答区域高度缩减为原来的一半，长回答仍可滚动读取。桌面右栏建议卡片紧接查询模块，使用剩余高度展开，不在两者之间保留自动空白。训练页查询布局保留原样。

# 能力意图、审核止损与自然语言摘要

更新：2026-10-31。提示词版本 `agri-temperature-v0.8-intent-recovery`。

## 本次故障的实际原因

失败任务 `7b618e83-784f-48bb-be64-d2e6a68bd25c` 的原问题为“你只能切面的测点吗，非切面的测点不知道吗”。运行记录中的模型 user_goal 已正确识别为能力范围问题，但程序更早因“测点”关键词锁定 field 路由，未用语义理解结果纠正执行计划。绑定快照的测点概览随后进入上下文，审核反复拒绝候选，最终触发 max_cycles，失败兜底又无条件发布了这些无关统计。

因此同时修正路由决策、上下文、审核反馈、失败发布与显示方式，不能只改一段提示词。

## 意图和执行权限

- 新增 capability 路由。明确的“只能处理切面吗”等能力问题优先识别；“帮我查一下当前坐标温度”等实际查询继续进入现场路线。
- 需求理解 JSON 增加 task_kind，提供当前实现的系统能力作为背景。语义理解可以在任何现场查询执行前将由绑定位置/关键词误选的路线校正为 capability 或一般知识；明确数值查询继续保持现场约束。
- “那你……”能力问题没有历史也能独立回答；有历史时，当前能力问题覆盖旧的数据查询目标。修正后的目标写入服务端上下文，防止后续继续继承错误任务。
- capability 仅注册 finish_answer，注入服务端 system_contract 功能清单；不注入当前测点统计、不注册现场读取和资料检索工具、不要求绑定快照。功能说明与具体读数查询分开。
- 清单依据当前 field_tools 的实现：支持有效三维重建网格内的点温、区域统计、双区域比较及极值；切面间的有效位置可查询重建值，不能冒充新增传感器实测；越界、拱外、无测量带或无效角点不能补值。没有历史趋势、预测、设备控制等工具。

## 审核规则

稳定的定性解释可以无文献引用，并用“一般来说”“在通常条件下”等措辞表达范围。2D、3D、C3、C4、CO2 等术语和段落编号不作为测量值误拦截。

软化词不豁免事实核验：无依据的精确温度、阈值、数量或处方仍拒绝；资料事实仍需有效来源，现场读数仍必须来自本轮快照。数字不匹配、定性文献冒充数值依据、未读原文与无效位置报温度等检查保留。审核提示对能力问题明确使用系统功能清单，不要求农艺文献或当前均温来证明系统支持什么。

## 连续两次同类失败的止损

按意图、依据、范围等失败类别统计连续失败，不再比较候选全文是否完全相同。引用缺失、数值缺依据和模型 factual_grounding / citation_entailment 归入依据问题；措辞变化、改一个数值或换一种来源缺失说明不会重置计数。真实检查通过则重置；为满足最低循环次数而要求再次提交，不计为审核失败。

连续两次同类失败抛出 review_stalled，结束主 Agent 循环，不追加第七、第八次主循环。

- 能力问题直接使用服务端功能清单给出有针对性的保守范围说明，不发布当前传感器统计。
- 其他问题在剩余时间、调用和 token 预算允许时，只尝试一次保守答案整理和一次独立审核，不重新检索、不重新进入 Agent 循环。只能发布审核通过的可确认内容，标记为 partial。
- 保守文本仍虚构数值或再次检查失败，则不发布草稿；给出围绕原问题的自然语言限制说明。
- 已通过具体查询工具确认、且与原任务相关的事实仍可作为部分结果保留。没有明确查询目标的测点概览不再无条件作为失败答案。
- 取消不触发额外整理请求；迟到结果继续受存储层取消保护。外部资料发布版本撤回检查在保守路径也保留。

## 摘要与执行日志的 UI

页面只把可公开的任务/执行摘要呈现为无编号自然语言段落，不强制固定的五句开头或固定阶段。内部原生 reasoning_content 保持服务端内存续接；不要求模型在 thought 标签中输出内部独白，也不将日志转换成伪造的内心独白。

公开摘要不渲染 F:sensor 等引用编号、不显示逐项“需要修订 / 未完成”标签。新审核记录更新同一个摘要节点；旧记录中连续的 review 节点在显示时合并为最后一次说明，原记录不重写。完整检查原因和修订反馈保留在服务器 review_history，属于诊断而非公开思考内容。

审核器另外输出一句按本轮问题撰写的 public_summary，显示实际检查结论与适用限制，而不是重复固定的“检查通过”话术；不含内部独白或工具/证据编号。旧格式审核响应仍能按简短检查结论兼容显示。

正文不再插入原生通道工程状态行。工具/模型执行记录和错误编号移入默认关闭的“查看执行诊断”，内部原有执行列表再折叠一层。来源与计算条件保留在原有“查看依据与计算口径”。紧凑输入框和页面外壳保留。

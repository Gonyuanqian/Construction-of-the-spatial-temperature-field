# 实时大屏监测地点选择窗口

更新：2026-11-09。

## 用户操作

点击实时大屏顶部的省市地区入口，打开 `MonitoringLocationDialog`。窗口只提供地点搜索、省市区联动选择和地图确认，不再显示 CSV 导入、气象值填写、模型配置、日期选择或生成温度场操作。

当前覆盖吉林省 9 个市州、60 个区县。名称与代码使用后台 `/api/user/regions` 返回的行政区字典。搜索支持城市、区县名称及省市县组合关键词，不声称支持尚未接入的乡镇或详细地址检索。

- 搜索结果或下拉选择定位地图，地图点选反向同步市县。
- 地图支持鼠标/触屏拖动、滚轮与按钮缩放、拖动位置标记、方向键微调标记。
- 仅允许选择本地行政区边界覆盖范围内的地点。区外点击不按最近城市静默吸附。
- 取消、关闭或 Escape 不保存草稿；确认后返回地点与坐标并关闭窗口。
- 已确认地点使用 `tfield.monitoring-location.v1.<账号ID>` 保存在当前浏览器，本次不新增数据库表。切换账号或退出登录时清空内存中的当前选择；重新登录同一账号可恢复该账号偏好。

## 地图数据

本地资源为 `frontend/public/maps/jilin-districts.json`。地图渲染为 SVG，打开窗口时读取本机资源，不向外部地图服务实时发送选点信息，不需要地图密钥，也不使用生成图片冒充可交互地图。

地图采用行政区边界呈现，未接入街道、道路导航、卫星影像或地址级地理编码。边界来源与采集日期保留在 GeoJSON 中及地图署名中：

- DataV.GeoAtlas：https://datav.aliyun.com/portal/school/atlas/area_selector
- 坐标说明：https://help.aliyun.com/en/datav/datav-7-0/user-guide/map-data-format-1
- 行政区名称代码来源：后端字典内的吉林省政务服务来源地址。

地图资源按后台当前名称重新匹配 60 个区县；资源中的代码采用后端字典，而非不经核对沿用旧地图代码。数据下载时检查完整覆盖，缺少匹配区县时停止生成。

选择结果保留 `coordinate_system: "GCJ-02"`、`longitude`、`latitude`，避免把地图坐标无标注传给后续气象服务。后续天气提供商适配应确认其经纬度坐标要求并处理坐标系差异，不应直接忽略此字段。

## 与监测数据的边界

本次只修改地点选择与大屏接线，不自动调用和风天气、不发起构场请求，也不根据地区重新挑选 G/F 模型。原气象接入层 lux 换算逻辑保持不变。

大屏顶部展示已确认的监测地区。若当前服务端结果属于其他市县，暂时隐藏旧读数和旧场，显示“等待该地点的气象构场结果”，防止把旧地点数据标成新地点。后台出现行政区相符的保存结果后，仍通过原有状态轮询和保存网格读取流程显示。

省市入口下的“气象 API 待接入”状态保留。完整自动气象链路仍需后续接入提供商请求、地点坐标与来源时刻的存储及匹配，不把地点确认描述成已生成新场。

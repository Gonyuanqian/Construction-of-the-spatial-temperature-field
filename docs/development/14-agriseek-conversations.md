# AgriSeek 多轮会话上下文

更新：2026-10-31。

会话事件回放、流式接口和前端节点组装的后续改造见 [deepseek-harness 对话交互设计应用](15-deepseek-harness-conversation.md)。

## 实际接入方式

浏览器每次发送 `conversation_id` 和 `parent_run_id`。后端验证父任务属于同一会话，并从 SQLite 的原始任务记录读取用户问题和已发布答案，组装为模型请求中的真实 `user/assistant` 历史消息。浏览器不上传或改写历史答案。候选生成和独立复核都能读取对话背景。

新对话使用新的会话编号；后端维护会话最新任务指针。同一会话同时提交或从旧父任务继续会返回 409，避免多个页面把不同分支混到一起。重复提交相同请求编号仍返回原任务。已取消、失败、重启中断的轮次不会伪造为成功回答。

## 历史预算与证据边界

- 默认最多选择最近 4 轮完整问答，历史消息总量最多 6000 UTF-8 字节，单轮问题和回答各最多 1600 字节，截短时保留标记。这是保守的输入预算，不声称字节数等于精确 Token 数。
- 当前问题、提示词、工具 schema 与本轮证据优先保留；剩余预算再装入历史。循环增长时如超出既有 32000 字节保守上下文额度，优先移除较早历史；总模型调用和执行预算继续生效。
- 历史只用于理解指代。旧回答不注册成本轮 F:/K: 事实；现场查询重新读取固定快照，农业知识重新检索当前发布清单，引用/数值检查仍执行。
- 历史答案只选取已发布 claims；不加入模型内部推理、分析过程、原始工具消息或审核器原文。失败/取消轮只提供状态。
- 本机当前仍为单工作区应用；会话间的上下文归属校验不等同于多用户权限隔离。

## 追问行为

「继续解释」「依据呢」「那 x=1.5 呢」等会关联本会话最近的有效任务。修改一个坐标时沿用其余坐标，并把修改后的坐标写入本轮目标。模型复核按当前目标判断，数值查询本身不要求作物与生育期。

单独一句「你回答错了」会定位上一轮的实际主题，询问具体需要更正的句子、数值或依据，不会把这句话当作农业检索关键词。附带具体更正要求时结合前文重新查询、生成和复核；不会默认旧回答或用户反馈一定正确。

重新绑定快照后标记 `snapshot_changed`，只注册新快照的现场事实。作物、生育期、坐标和区域表单会在切换会话或模型完成解析后恢复；显式清空作物条件生效。

## 服务端历史与旧记录

- `GET /api/assistant/conversations`：按更新时间返回最近 100 个会话摘要。
- `GET /api/assistant/conversations/{id}`：返回该会话最近 100 轮及最新任务编号；`has_older` 标记更早记录。完整记录仍保存在 SQLite。
- Java 提供同名业务入口，内部凭据仍只由服务端携带。
- 刷新或切换会话时优先读取服务器历史，浏览器缓存作为兼容与界面恢复用途。
- 旧版记录缺少服务端会话归属。首次续聊可提交本地历史最近 20 个任务编号 `legacy_run_ids`；服务端读取原始内容、核对顺序和未被其他会话占用的状态后，在事务内迁移关联。不能提交历史答案文本冒充原记录。旧客户端仅指定上一任务时，兼容接续一个尚未归属会话的旧任务。

## 错误诊断

新增 `error_code` 与结构化 `diagnostic`，记录失败类别、发生于模型/知识检索/上下文哪个环节、异常类型，以及适用时的 HTTP 状态码。不会返回密钥、认证头、供应商响应正文或异常堆栈。模型工具协议错误、输出截断、上下文预算、知识服务连接失败等不再统一显示为「证据检查失败」。

## 验证入口

后端：`python -m pytest tests/test_assistant_conversation.py tests/test_assistant.py tests/test_assistant_analysis.py tests/test_assistant_field_tools.py tests/test_volume_sample.py -q`。

前端：`npm test -- src/views/AssistantView.test.ts src/components/AssistantAnalysis.test.ts src/App.test.ts`。

独立三轮验收：`python -X utf8 backend/scripts/evaluate_assistant_conversations.py`；加 `--live` 使用真实 DeepSeek，只发送独立线性场测试数据。报告在忽略目录 `.local/assistant/conversation-scripted.json` 和 `conversation-live.json`，重新运行保留旧报告。测试结果不代表农艺专家验收或模型服务长期稳定。

本轮后端回归 77 项、前端相关测试 29 项通过，前端与 Java 构建通过。模拟供应商三轮验收 3/3；最终真实 DeepSeek 三轮验收也为 3/3：首轮 15°C，单独修改 x 后 17°C，纠错轮关联对应任务并请求具体更正信息。前两次真实验收各有一轮未完整发布，保留了工具确认数值与错误状态；未将这些任务计为完整回答成功。随后补充了当前坐标优先和纯数值查询的适用性复核说明，再完成最终验收。

# 用户工作台导航与原监测大屏恢复

记录日期：2026-11-05。以下保留当时的实现记录。2026-11-06 起已删除独立实时回放页面，气象输入合并到监测页，当前导航和使用方式以 [单一实时监测入口](30-single-live-weather-demo.md)为准。

## 页面归属

| 地址 | 页面实现 | 权限及数据 |
| --- | --- | --- |
| `/live` | `LiveView.vue` 原三维大屏 | ADMIN / USER；`/api/live/**` 读取本账号最新保存的气象构场 |
| `/replay` | `UserLiveView.vue`，标题“实时回放” | ADMIN / USER；`/api/user/**` 输入气象、匹配地区档案并查个人历史 |
| `/assistant`、`/assistant/field/:snapshotId` | AgriSeek 与快照 | ADMIN / USER；经 Java 身份校验、按账号隔离普通用户的助手数据 |
| `/data`、`/train`、`/models`、`/field`、`/admin/**` | 开发者后台 | 仅 ADMIN；不再含实时回放和 AgriSeek 导航 |

根地址、未知地址及 `/developer/live` 转到 `/live`；旧 `/monitor` 转到 `/replay`。用户侧不再通过角色选择两个不同的实时首页。`AuthenticatedShell` 仅在 `/replay` 使用两列气象布局，`/live` 恢复原三列外壳及右侧 `#shell-side` 查询栏。两个监测工作台跨页面保留实例，退出或更换身份仍销毁。

`LiveView` 不再依赖仅管理员可读的模型库接口；通过用户档案接口判断部署是否可用，并始终检查本账号最新结果。没有正式模型、档案或保存结果时如实显示空态，不把隔离验收的模型和天气写入正式库。

2026-11-05 补充修正：空态不能隐藏整套大屏。未就绪时保留概览、画布、环境参数、沿棚均温与右侧查询/视图控制的布局；数字为“暂无”，画布使用中性网格占位，查询禁用。无档案、无气象结果、读取失败分别提示，不生成示例温度。idle 时也轮询状态，配置和结果到达后可自动进入正常展示。首次同步渲染时右栏可能尚未挂载，`useRetainedTeleport` 先就地渲染，挂载后连接外壳目标。

## 保留的数据边界

前端 `/replay` 与后台 `/api/replay/**` 含义不同：前者是用户的气象输入与已存结果页面，后者是旧 XLSX 全局文件回放接口，仍仅 ADMIN 可访问。不能为了用户导航而开放后者。

`/live` 的画布、环境参数、均温曲线、空间查询和视图控制保持原实现；数据继续来自“外部气象 → G 预测虚拟测点 → 冻结 F 构场”。虚拟源不改标为实测。原播放按钮未适配新驱动方式，开始/暂停/下一帧仍返回 409 与说明；后续可单独设计气象提交、刷新和历史选择交互。

## AgriSeek 账号隔离

Java `/api/assistant/**` 允许 ADMIN / USER，但不信任浏览器传来的所属用户头。普通用户命名空间来自认证主体的 UUID，Java 在内部请求中附加 `X-TField-Assistant-Owner`；先检查 Python `GET /internal/v1/assistant/info` 的 `owner_isolation_version=1`，协议不兼容时拒绝转发。内部接口仍要求服务密钥。

Python 用请求级 `ContextVar` 选择助手 SQLite 存储：普通用户保存于 `TFIELD_ASSISTANT_STATE_ROOT/users/<UUID>/runs.sqlite3`；管理员保留原根目录数据库，兼容既有管理员历史。该兼容行为意味着多个管理员仍共用旧管理员助手历史，并非每个管理员一份。普通用户不能读取此历史，也不能跨用户读取、取消或订阅任务、会话及快照。天气快照使用同一命名空间。

异步任务提交通过 `copy_context().run` 继承所属账号，SSE 请求在整个流存续期间保留上下文。后续增加线程池或新流式入口时也需保持此规则，否则请求结束后的工作可能落入管理员根目录。

浏览器历史键为 `tfield-assistant-chats-v3:<ROLE>:<ID>`。只允许管理员兼容读取旧共享本地历史；普通用户不迁入旧管理员缓存。统一启动脚本把助手状态根目录固定在项目 `.local/assistant`，发布切换不改变历史位置。

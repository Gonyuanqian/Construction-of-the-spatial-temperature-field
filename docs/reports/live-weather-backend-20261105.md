# 实时监测外部气象后端验收

日期：2026-11-05。业务版本 0.6.0；无新增数据库迁移。

## 本轮结果

实时监测 `/api/live/**` 改为外部气象驱动，复用 `WeatherService` 和已有 G/F 模型链路。输入所在地、带时区时刻、背景温度、背景光照，按模型需要提供背景湿度；不接受棚内 24 点输入。24 个虚拟温度由第一阶段模型生成，再由冻结第二阶段恢复构场。新入口为 `POST /api/live/weather`，原 `POST /api/live/prepare` 也支持气象请求体。

两种提交入口使用同一份 `weather_frame`、同一个账号和地区历史，不重复训练模型。状态、断面、三维、点查询、助手快照均绑定该账号已保存的气象结果，读请求不调用文件源、不拟合或重新推断。源平面及点查询不标成实测；原传感器字段为 null，预测点使用独立字段。原文件回放保留在管理员专用 `/api/replay/**`，普通用户不能访问。

协议、输入示例、固定网格限制、旧播放操作的 409 提示见 [开发交接](../development/25-live-weather-backend.md)。

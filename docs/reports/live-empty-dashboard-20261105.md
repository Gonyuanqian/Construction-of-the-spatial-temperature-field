# 实时监测空白页修正

用户在正式本机页面看到整屏只剩“暂无可用的气象构场”，与此前提供的隔离环境截图不一致。

原因：`LiveView.vue` 仍以 `hasModel` 与 `ready` 两层条件包住整个大屏。正式环境无可用结果时，画布、环境参数、沿棚均温及查询栏一起被移除。此前只恢复页面组件、用有数据的隔离环境验收，遗漏了正式空态。

本次修正保持原页面布局：没有数据时保留各模块，温度、尺寸、更新时间显示“暂无”，画布显示中性网格与等待提示，查询和视图控制禁用。不填入测试数据，不恢复旧 24 路实测输入。缺少档案、尚无个人气象结果、接口失败分别提示；已有保存结果不受档案列表暂时失败影响。

idle 时继续轻量检查 `/api/live/status`，新结果出现后自动加载；手动刷新同时检查档案与状态。无结果时不发送 frame/volume/point 或准备管线请求。右栏 Teleport 首次渲染改为挂载后连接目标，避免同步空态在外壳 DOM 尚未就绪时丢失或报错。

验证：前端类型检查和构建通过；`LiveView.empty.test.ts`、`auth-shell.test.ts`、`auth-navigation.test.ts`、`UserLiveView.test.ts` 共 22 项通过，覆盖无档案、无结果、连接失败、已有结果、空态与结果转换、无档案时自动发现结果、退出销毁和角色路由。日志为 `.local/live-empty-build.log`、`.local/live-empty-tests.log`。

当前本机为 Dev 模式，5173 直接使用工作区前端源码，本次无需修改数据库、重启后端或更换账号。8080 所指既有发布包仍是上一版本，下一次正式打包时应包含本次前端产物。
